## 📂 Estructura del Repositorio
El repositorio está organizado de manera lógica para mantener el orden del código fuente a lo largo del ciclo académico:

* 📁 `Laboratorios/`: Prácticas cortas y ejercicios guiados realizados en clase.
* 📁 `Tareas/`: Asignaciones y trabajos de desarrollo independiente.
* 📁 `Proyectos/`: Entregables parciales y finales del curso (Frontend y Backend).

## 🛠️ Tecnologías y Herramientas
A lo largo de este curso, se utilizarán y explorarán diversas tecnologías enfocadas en el desarrollo web, tales como:
- HTML5 & CSS3
- JavaScript (ES6+)
- Frameworks / Librerías (según los requerimientos de cada actividad)
- Bases de Datos y conexiones Backend
  
## 📝 Notas
Este espacio servirá como bitácora para documentar los aprendizajes clave, arquitectura de software aplicada al entorno web y mejores prácticas adquiridas durante el semestre.
